# 🎯 Project Overview

This project demonstrates a real-world style **DevOps environment** running on
an **AWS EC2 Ubuntu server**.

The environment uses Docker and Docker Compose to manage multiple services,
while Jenkins is used for CI/CD automation and Prometheus + Grafana are used
for monitoring and visualization.
